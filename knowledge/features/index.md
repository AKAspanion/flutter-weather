# Features

<!-- GA-GENERATED:index -->

- [Look up a city](city-search.md) - The location button opens a dialog where the user types a city; the app remembers it until refresh switches back to the device location.
- [See the current weather](current-weather.md) - At launch the app shows the last report at once, then fetches fresh weather for the device location or the saved city; refresh does the same.
- [See the forecast](forecast.md) - A panel that slides up with the next 48 hours as expandable chips and the next days as expandable cards.
- [Android home-screen widget](home-screen-widget.md) - One resizable Now card in the app's accent, with an animated weather icon, fed by the app and refreshed in the background for the last place viewed.
- [Choose a theme and an accent](themes-and-accents.md) - The theme follows the system light or dark, the menu button overrides it until the system changes, and accent gradients picked from a carousel also colour the widget.
